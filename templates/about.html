About SalesAI

An AI-powered Sales Forecasting & Demand Prediction System designed to estimate future store sales using machine learning.

Sales Forecasting & Demand Prediction System

SalesAI is a machine learning based web application that predicts daily store sales from historical sales data and important business factors. The system uses an XGBoost Regressor to learn relationships between store characteristics, promotions, holidays and time-based features.

The prediction results are stored in a CSV file and displayed through an interactive dashboard for monitoring sales predictions and business trends.

🎯

Project Objective

Predict expected daily sales and support better business planning using machine learning.

📊

Business Analytics

Transform prediction results into meaningful KPIs, trends and historical insights.

🤖

AI Prediction

XGBoost regression is used to generate accurate sales forecasts from multiple input features.
